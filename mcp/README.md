# GDC AI エージェント接続（MCP）v0.18.0

Claude Code などの AI エージェントが、GDC の**画面と同じ操作**を実行するための入口です。

```
AI エージェント ⇄ (MCP: 標準入出力) ⇄ mcp/gdc-mcp.mjs ⇄ (http://127.0.0.1 だけ) ⇄ ブラウザで開いた GDC の画面
```

- 形を作るのは画面（GDC 本体）です。AI の操作はタイムラインに **🤖 付きで 1 手ずつ**残り、人がダブルクリックで直したり、Ctrl+Z で取り消したりできます。
- 1 回の道具（ツール）= 元に戻す 1 回。**失敗した道具はモデルを変えずに**エラーを返します（履歴は壊れません）。
- サーバーは **127.0.0.1 だけ**で待ち受け、外部には何も送りません。起動のたびに変わる合言葉（URL の `?agent=…`）のない接続、ほかのサイトのページからの接続は断ります。GDC 本体もこのフォルダから配るので、インターネットなしで動きます。
- 依存パッケージはありません（Node.js 18 以降だけ）。

※ AI エージェントそのもの（Claude Code など）が、受け取った結果をどう扱うかはそのエージェントの設定によります。GDC とこのサーバーは外部に送りません。

## つなぎ方

1. AI エージェントにサーバーを登録します（例: Claude Code）

   ```bash
   claude mcp add gdc -- node /path/to/gdc-cad/mcp/gdc-mcp.mjs --open
   ```

   `--open` を付けると、最初に道具を使うときに既定のブラウザで GDC の画面を開きます。付けないときは、エージェントが案内する URL（`http://127.0.0.1:47830/?agent=…`）を開いてください。
2. 画面の上に **「🤖 AI 接続」** と出ればつながっています（クリックで AI の操作の記録）。
3. あとは「60×40×5 の板の四隅に Ø5 の穴をあけて」のように頼むだけです。

| オプション | 内容 |
|---|---|
| `--port 47830` | 待ち受けるポート |
| `--app <フォルダ>` | GDC 本体（index.html と assets）の場所。既定はこのフォルダの 1 つ上 |
| `--out <フォルダ>` | STEP / STL / .kcad の保存先。既定は今のフォルダの `gdc-output` |
| `--open` | 既定のブラウザで画面を開く |
| `--headless` | 画面を出さずに動かす（Playwright と Chromium が必要。自動処理・テスト用） |
| `--allow-origin <URL>` | 公開版（GitHub Pages）の画面から `&agenthost=http://127.0.0.1:47830` を付けてつなぐのを許す（Chrome のみ・任意） |

画面のタブは 1 つだけつながります（2 つ目のタブには「別のタブが AI 接続中」と出ます）。画面でスケッチを編集している間は、人の作業を壊さないように AI の道具はエラーになります。

## 道具（ツール）

| 道具 | 内容 |
|---|---|
| `get_state` | ボディ一覧（体積 mm³・重心・外形・大きさ）、タイムラインの手順と寸法（`by: "ai"`）、スケッチの拘束状態（完全拘束／拘束不足・自由度）、パラメータ |
| `create_box` | 直方体（width・depth・height・position・name） |
| `create_sketch_extrude` | XY/XZ/YZ 平面かボディの面に、長方形・円を描いて押し出し（new / join / cut / intersect、through_all） |
| `create_hole` | 面の角からの座標で穴（貫通・深さ指定） |
| `modify_feature` | 既にある手順の寸法を変えて再計算（例: `{"target":"テスト部品","set":{"thickness":8}}`） |
| `run_commands` | 画面の「AI に頼む」と同じ GDC コマンド（docs/コマンドの使い方.txt）をまとめて実行 |
| `undo` | 取り消し（AI の道具 1 回 = 1 手） |
| `export_file` | STEP / STL をファイルに保存。STEP は形状エンジンで読み戻して体積の一致を確認 |
| `save_project` | .kcad（履歴付き）で保存。画面の「ファイルから開く」で開ける |

## 「AI に頼む」との関係（拡張）

画面の「AI に頼む」（端末内 AI・自分の PC の AI・Claude など）は**そのまま**です。MCP は外部の AI エージェント向けの**もう 1 つの入口**で、
どちらも同じ実行役（コマンドの実行・タイムライン・元に戻す）を通ります。`run_commands` では「AI に頼む」と同じコマンドが使え、
AI 接続の操作は「AI に頼む」の記録欄にも 🤖 付きで残ります。
