# GDC GOOD DESIGN CAD

ブラウザで動く 3D CAD（パソコン・iPhone 対応）。

- 使う: このリポジトリの GitHub Pages の URL を Safari / Chrome で開く（iPhone は「共有 → ホーム画面に追加」）
- 「内装」: 部屋の 3D スキャン（iPhone の LiDAR アプリの OBJ / PLY / GLB）や間取り図・部屋の写真を読み込み、方針を書くと家具・造作を自動で配置して、平面図・展開図・部材表（PDF / DXF / CSV）を出力。造作は板ごとの部品として 3D CAD に送れます
- 設計データは使っているブラウザの中だけに保存され、外部には送られません
- ソースコード: `source/gdc-cad-src.zip`、同梱ソフトのライセンス: `THIRD_PARTY_LICENSES.txt`
